术语表

模组生态里的常用词，中英对照。

常用词对照

中文 英文 说明
模组 Mod 修改游戏内容的程序
加载器 Mod Loader 负责加载模组的框架
前置 Dependency 别的模组运行前必须装的东西
数据组件 Data Component 1.21 起替代 NBT 的物品数据容器
注入 Mixin Injection 在运行时修改已有类的方法
重载 Reload 不重启游戏刷新数据与资源
服务端 Server Side 只在服务器运行的一侧
客户端 Client Side 只在玩家本地运行的一侧
整合包 Modpack 打包好的一整套模组与配置
附属 Addon 依赖另一个模组运行的小模组

常见缩写

  • AoT：Attack on Titan（进击的巨人相关模组）
  • LSO：Legendary Survival Overhaul
  • KIPL：Kill Inspector
  • SQDCLib：叙事前置库
  • WPM：Words Per Minute，打字速度
