Minecraft 模组

Mornfrost Office 的模组作品，以 NeoForge 1.21.1 为主阵地，涵盖内容扩展、服务端优化与服务器管理工具。

Mornfrost Achievements

Minecraft 模组 · 多平台 · 当前版本 v5.0.0

Mornfrost 整活成就合集：300+ 条风格各异的成就，从正经挑战到网络梗全覆盖。

  • 平台覆盖：NeoForge 1.21.1 · Fabric 1.21.1 / 1.21.11 · Forge 1.20.1
  • 新增多个成就分类与分支，涵盖探索、战斗、建造、模组交互等维度
  • 轻量级设计，无冗余依赖

SoulGlyph 灵铭

Minecraft 模组 · NeoForge 1.21.1 · v1.0.0

Curios 饰品槽位驱动的铭文物品系统。

  • 42 条基础铭文，两两融合出 903 种融合铭文（金铲铲式合成）
  • 品质五档：普通 / 稀有 / 史诗 / 传说 / 神话，加成 10% - 40%
  • 专属 glyph 槽位，装备即生效；融合铭文附带专属特殊效果
  • 另提供「养老版」休闲变体（v1.1.0-sp1.0）

Soulbound Blades 缚魂之刃

Minecraft 模组 · NeoForge 1.21.1 · v1.1.0

原版风格武器扩展模组：20 把独特的剑，以「谜语 → 试炼 → 进化」为主线。

  • 四个阶段的武器进化体系，每把剑都有专属试炼与成长路线
  • 武器数值、Lore、试炼文案全部 JSON 数据驱动，支持 /reload 热更新
  • 配套 Soulbound Lore Patch（v1.1.0）提供 Lore 修正补丁

Arsenal

Minecraft 模组 · NeoForge 1.21.1 · v1.0.0

跨文化武器扩展模组。

  • 6 种新矿物，29 类中式 / 日式 / 西式武器（共 174 件）
  • 72 件层级护甲，完整的矿物 - 武器 - 护甲合成体系
  • 武器数据通过 DataComponent 持久存储，数值可在 /reload 时热调整

Echoes of the Unbound · 未缚回响

Minecraft 模组 · NeoForge 1.21.1 · v1.0.0

维度扩展模组：五个破碎的维度，四个同行者，一条以告别写成的主线故事。

  • 完整的多维度主线剧情与角色塑造
  • 每一次死亡都有专属运镜演出：黑边、字幕、镜头轨迹
  • 剧情与美术编排一体化设计

Forge of Ascension

Minecraft 模组 · NeoForge 1.21.1 · v1.0.0

装备强化模组。

  • 将两件同类型、同强化等级的装备在强化台中融合，生成属性更强的装备
  • 强化等级越高，成功率越低；失败时材料全部损毁
  • 高风险高回报的装备成长循环

Culinary Construct（NeoForge 移植）

Minecraft 模组 · NeoForge 1.21.1 · v6.1.0+1.21.1

经典烹饪模组 Culinary Construct 的 NeoForge 1.21.1 移植版，原作为 Illusive Soulworks。

  • 自由组合食材，制作三明治等自定义食物
  • 保留原版玩法的同时适配新版 API 与数据组件

MemoryMaster

Minecraft 模组 · NeoForge 1.21.1 服务端 · v1.0.0（modId: mmcmf）

服务端堆内存优化模组。

  • 7 个优化模块默认全开、可逐个关闭，每个模块独立 mixin 文件
  • 注入前校验目标类与成员是否存在，异常自动降级为原版行为
  • 首次加载两段式自检，提供 /mmcmf panic 一键回退

BanItemBlock

Minecraft 模组 · NeoForge 1.21.1 服务端 · v1.0.0

按配置文件全量清除指定方块与物品的服务器管理模组。

  • 方块与物品禁用清单分成两个互不影响的 TOML 配置文件
  • 支持全量清场，适合服务器内容管控

Enchantment Remover

Minecraft 模组 · NeoForge 1.21.1 · v1.0.0

彻底删除指定附魔。

  • 被删除的附魔不会出现在附魔台，也不会通过宝箱战利品、钓鱼宝藏、村民交易等途径生成
  • 物品上已有的该附魔将完全失去效果
  • 在 config/enchantremover-common.toml 中按命名空间填写附魔 ID 即可

Per-Dimension Respawn

Minecraft 模组 · NeoForge 1.21.1 服务端 · v1.0.0

各维度独立出生点。

  • 修复原版单一全局出生点的问题：在地狱设重生锚、在末地设出生点不会再覆盖主世界的床
  • 死亡后回到死亡维度自己的出生点，维度之间互不干扰

Login Mod

Minecraft 模组 · NeoForge 1.21.1 服务端 · v1.0.0

服务端登录 / 注册模组。

  • 新玩家 /reg 注册一次，之后每次进服 /login 登录
  • 未登录期间冻结、失明、无敌，且无法聊天、执行命令、破坏 / 放置方块、攻击和拾取物品

KIPL - Kill Inspector

Minecraft 模组 · NeoForge 1.21.1 服务端 · v1.0.0

击杀查询模组，回答一个问题：哪个玩家最近被哪个玩家杀死了？

  • /kipl 查询最近一次玩家击杀的时间、地点与渠道
  • 游戏内事件与控制台日志双通道检测，互相印证

DeletePortal

Minecraft 模组 · NeoForge 1.21.1 服务端 · v1.0.0

Danny’s AoT 附属模组。

  • 世界生成阶段扫描清除帕拉迪岛传送门（dannys-aot:paradis_portal），替换为空气
  • /deleteportal 指令查询已清除数量

Giants on Grass

Minecraft 模组 · NeoForge 1.21.1 · v1.0

Danny’s AoT 附属模组，由 Mornfrost 移植到 NeoForge 1.21.1。

  • 让巨人（Titans）只在草方块上生成
  • 生成范围可配置

中国人能飞

Minecraft 模组 · NeoForge 1.21.1 · v1.0.0

趣味模组：当游戏语言为简体中文、繁体中文或文言文时，玩家获得创造模式的飞行能力。

  • 一旦切换为其他语言，飞行立即失效
  • 简单直接的语言检测逻辑，即装即用
