作品 / 模组

Ymondf · 月神

NeoForge 1.21.1 · 前置 SQDCLib / GeckoLib · 0.3.3

叙事冒险，「九加一」ARG 的第一个质点。睡一觉会收到一个档案袋，按里面的页走；再往后是月神和它的月相竞技场。0.3 里加了两个阶段的机制 Boss、四语配音，还有一枚能召唤月神残影的月相盘。

叙事冒险，「九加一」ARG 的第一个质点。

为什么做它

Minecraft 里的叙事模组大多走向两个极端：要么是纯文本对话，玩家点"下一步"点到麻木；要么是任务系统，把故事拆成一串勾选项。Ymondf 想做第三种：不给任务列表，不给指引箭头，只给一个物件——档案袋——然后让玩家自己按页里的指示行动。

这是「九加一」ARG 的第一个质点。所谓质点，是指整个故事从这里开始坍缩。

它是怎么运作的

档案袋叙事：第一次真正睡过夜后，玩家会收到一个档案袋。右键打开是自己的阅读界面，不是原版书本。第一页给出一个动作，做完之后第二页才会填上玩家自己的数据，然后指向下一个地点。页码推进依赖于玩家的实际行为，而不是时间。

月神与月相竞技场：中后期会进入悬浮于虚空的石盘舞台，与月神交战。0.3 版本加入了两阶段的机制 Boss「无风」：一阶段本体可伤但有伤害窗口，二阶段本体不可伤，场地绕行三枚风核，同一时刻只有一枚在充能，伤害要经核转发。风核每 20 秒轮换，压力场与风眼按固定节奏刷新。

四段大招过场：永夜降临、断空剑阵、耀斑净化、天地同寿。四段都是程序化 3D 渲染出来的全屏过场（1920×1080 / 30fps / 2.39:1 遮幅），音效由脚本合成并与画面节拍对齐。

素材：月面贴图取自 NASA SVS 的 LRO/LROC 实测数据（公有领域），其余贴图——档案袋、残页、木头、血条、光晕、月相盘——全部由工具脚本生成，没有外部美术资源。

配音：0.3.2 起提供英、日、韩、繁中四套配音，按客户端语言选轨，缺轨时依次回退。

怎么用

前置 SQDCLib 与 GeckoLib（两个 jar 都在发布包里，跑游戏前要复制进 run/mods 或 mods）。

流程：

  1. 装好前置与本体
  2. 进世界，第一次睡过夜
  3. 收到档案袋后右键打开，按第一页的指示做
  4. 完成动作后再次打开档案袋，第二页会填上你的数据

不战斗、不做任务系统，档案袋是自己的物品，阅读界面是自己的 Screen，没有改动任何原版资源。

取舍与边界

不做任务 UI。没有列表、没有勾选、没有箭头。线索只在档案页和对话里，看不懂就是看不懂——这是 ARG 的一部分。

不做自动存档点。进度写在玩家自己身上，跟着存档走；换存档等于重开。

版本还在推进。0.3.3 仍是 beta 线，机制 Boss 的数值和演出还在调，不建议直接上大型公开服。

版本与依赖

当前 0.3.3。NeoForge 1.21.1 / Java 21，前置 SQDCLib、GeckoLib。MIT 协议。0.3 系列的主要变化：两阶段机制 Boss、月相盘改为真召唤月神残影、四语配音、第四页档案。

开发与验证流程

这类叙事模组的开发成本大头不在代码，而在验证。每一页档案、每一段对话、每一场演出都要在真实客户端里跑一遍：字体是否溢出、字幕是否对齐、镜头是否穿墙、死亡运镜会不会卡住玩家操作。0.3.1 修复的就是这类问题——三个 NPC 的第二轮对话节点没接回对话图，导致任务第 9 步死锁；任务步骤里的场景 ID 和真实链节点对不上，进度卡在 16/20。

0.3.2 的重点是机制 Boss「无风」。两阶段设计里，二阶段本体不可伤，伤害要经三枚风核转发，风核每 20 秒轮换充能。这套机制的验证不能只看数值，还要确认"非充能核的提示"是否足够清楚——玩家看不懂提示，就会以为 Boss 无敌。

演出与配音

四段大招过场是程序化渲染的，不依赖游戏内引擎，所以可以在游戏外反复调镜头和节奏，定稿后再接进模组。配音按语种分轨，缺轨时依次回退；英文鸣谢改成了完整姓名，四个语种分别列出配音员。

月相盘在 0.3.2 改成了真召唤：不再从创造栏直接拿，而是击败月神后结算发放，使用后召唤月神残影（本体 1/80 属性、55% 体型、只有空手攻击、玩家打不伤它）。这个改动是为了让"月神"这个意象在通关后仍然存在，而不是打完就结束。
