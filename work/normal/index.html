MFoC 服务器

从零搭建并长期运营的模组服务器，现已停运。

  • 服务器整体架构设计与搭建
  • 模组包配置与长期维护
  • 官网及文档站开发
  • 玩家社区运营

MFoC Station

服务器信息站客户端 · Kotlin Multiplatform + Compose Multiplatform

独立于 Minecraft 客户端的外部应用，提供服务器状态、公告、模组与快速入口。

  • 一套代码同时构建 Android 与 Windows 桌面应用
  • 服务器状态实时查看、公告推送、模组列表与快速入口

MFoC Station Desktop

Windows 桌面版信息站 · Kotlin (JVM) + Compose Multiplatform + Ktor + Material 3

  • 可调整窗口的桌面端体验
  • 附带 Inno Setup 安装程序，开箱即用

MFoC Station Harmony

HarmonyOS NEXT 原生版 · ArkTS + ArkUI（Stage 模型，API 12 / HarmonyOS 5.0）

  • 从零实现的鸿蒙原生版本，与 Kotlin 版功能对齐
  • 针对 HarmonyOS 设备的兼容性适配方案

FlexLauncher

通用 Minecraft 启动器 · .NET 8 WPF

由 config.json 完全驱动的启动器：启动器本身不绑定任何服务器或整合包。

  • 服主只需修改 exe 旁的 config.json，即可得到属于自己的定制启动器
  • 无需重新编译，分发即用

dimension-transfer

Velocity 代理插件 · Java

  • 监听玩家切换维度的数据包，按维度把玩家转发到 main / other 两个后端之一
  • 支持跨后端维度分流的代理拓扑
