应用与工具

非模组项目：信息站、启动器、代理插件与服务器运维工具。

01

MFoC Station

信息站客户端 · Kotlin Multiplatform + Compose

独立于游戏运行的外部应用：查看状态、公告、模组列表与常用入口。

  • 一套代码同时构建 Android 与 Windows 桌面
02

MFoC Station Desktop

Windows 桌面版 · Compose Multiplatform + Ktor

可调整窗口的桌面端信息站。

  • 附带 Inno Setup 安装程序，开箱即用
03

MFoC Station Harmony

HarmonyOS NEXT · ArkTS + ArkUI

从零实现的鸿蒙原生版本，与 Kotlin 版功能对齐。

  • 针对 HarmonyOS 设备的兼容性适配方案
04

FlexLauncher

通用 Minecraft 启动器 · .NET 8 WPF

由 config.json 完全驱动的启动器，本身不绑定任何服务器或整合包。

  • 服主改 exe 旁的 config.json 即可得到定制启动器
  • 无需重新编译，分发即用
05

dimension-transfer

Velocity 代理插件

按维度把玩家转发到 main / other 两个后端之一。

  • 监听玩家切换维度的数据包，支持跨后端维度分流
06

serverbackup

Windows 原生 exe · v1.1.0

给服务器用的定时备份工具，纯 Windows 原生实现。

  • 先复制存档再压缩归档，内置 7-Zip，零外部依赖
  • 命令行守护进程 + 图形「立即备份」两个程序
  • 可与关服工具联动，组成关服 → 备份 → 开服
07

autoclose

Windows 原生 exe · v1.0.0

服务器运维用的定时关服 / 关进程工具。

  • 礼貌关闭（Ctrl+Break 让服务端先存盘）与强制结束两档
  • 关键进程保护；图形设置界面与配置文件双向同步
08

MFoC 文档站

建站项目 · Hexo + Fluid

服务器官方文档站：模组介绍、技术文档与管理团队。

  • 内容架构设计与主题配置
09

MFoC 服务器

Minecraft 模组服务器 · 270+ 模组 · 已停运

早期的模组服务器项目，从架构搭建、模组包配置到社区运营都由工作室完成。

  • 现已停运，作为历史项目存档
