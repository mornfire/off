应用与工具

非模组项目：信息站、启动器、代理插件与服务器运维工具。

01

MFoC Station

服务器信息站，装在看板或手机上都能用。状态、公告、模组列表和常用入口放在一处，不用开着游戏查。

信息站客户端 · Android + Windows
02

MFoC Station Desktop

同一套东西的桌面版。窗口可以随意拉，附了安装程序。

Windows 桌面版 · Compose + Ktor
03

MFoC Station Harmony

鸿蒙原生版，用 ArkTS 重写，功能与 Kotlin 版对齐。

HarmonyOS NEXT · ArkTS + ArkUI
04

FlexLauncher

一个不绑定任何服务器的启动器：改改 exe 旁边的 config.json，就是你的定制启动器，不用重新编译。

通用启动器 · .NET 8 WPF
05

dimension-transfer

玩家跨维度时按维度把人转到不同的后端，两个世界的负载分开。

Velocity 插件
06

serverbackup

定时备份服务器存档。先把文件复制到安全位置，再压缩归档；命令行守护进程管定时，图形版用来手动点一下。

Windows exe · 1.1.0
07

autoclose

配合备份用的关服工具。到点先礼后兵：给服务端发个存盘信号，等几秒，再不行才强杀。

Windows exe · 1.0.0
08

MFoC 文档站

服务器的文档站，模组介绍、技术文档和管理团队都在里面。

站点 · Hexo + Fluid
09

MFoC 服务器

早期的模组服务器项目，270 多个模组，从架构到社区运营都是自己做的。现在已经停了，留个存档。

模组服务器 · 270+ 模组 · 已停运
